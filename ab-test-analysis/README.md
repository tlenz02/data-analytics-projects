# A/B-тест рекомендательного алгоритма

## Описание проекта

Анализ A/B-теста нового рекомендательного алгоритма. В рамках проекта проведён анализ исторических данных, рассчитаны параметры эксперимента, проверена корректность распределения пользователей между тестовыми группами и оценено влияние нового алгоритма на вовлечённость пользователей.

**Ключевая метрика** — доля первых сессий, в которых пользователь просмотрел 4 и более страниц.

## Цель

Определить, приводит ли новый рекомендательный алгоритм к статистически значимому росту доли успешных первых сессий по сравнению с текущей версией.

## Что сделано

* исследованы исторические данные о пользовательских сессиях;
* проанализировано распределение просмотров страниц в первой сессии;
* рассчитан базовый уровень ключевой метрики;
* определены необходимый размер выборки и минимальная длительность эксперимента;
* проверен баланс тестовых групп по количеству пользователей;
* проверено отсутствие пересечений пользователей между группами A и B;
* сопоставлены распределения групп по типам устройств и регионам;
* сформулированы статистические гипотезы;
* рассчитано изменение ключевой метрики;
* проведена односторонняя статистическая проверка результата A/B-теста.

## Результаты

Для эксперимента была рассчитана необходимая выборка около **41 040 пользователей на группу**, минимальная расчётная длительность — **9 дней**.

На этапе проверки сплита критических нарушений обнаружено не было: группы были сопоставимы по размеру, устройствам и регионам, пересечений пользователей между группами не выявлено.

По итогам эксперимента:

* группа A — **31,57%** успешных первых сессий;
* группа B — **31,47%**;
* изменение B − A — около **−0,11 п.п.**;
* `p-value = 0.578` при уровне значимости `α = 0.05`.

Статистически значимого роста ключевой метрики в тестовой группе не обнаружено.

**Вывод:** текущая версия нового рекомендательного алгоритма не показала ожидаемого положительного эффекта. Результаты эксперимента не дают оснований рекомендовать его внедрение на основе выбранной ключевой метрики.
