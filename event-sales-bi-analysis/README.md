# Анализ продаж билетов и BI-дашборд

## Описание проекта

Анализ данных о продажах билетов сервиса Яндекс Афиша с использованием SQL и визуализация ключевых бизнес-показателей в Yandex DataLens.

В рамках проекта рассчитаны основные метрики продаж, исследовано распределение выручки по устройствам, типам мероприятий и регионам, а также построен интерактивный дашборд для анализа показателей в динамике.

## Цель

Проанализировать структуру и динамику продаж, определить наиболее значимые сегменты и представить ключевые показатели в удобном для мониторинга интерактивном дашборде.

## Что сделано

* рассчитаны общая выручка, количество заказов, средняя выручка на заказ и количество уникальных пользователей;
* проанализированы выручка и количество заказов по типам устройств;
* рассчитана доля каждого типа устройства в общей выручке;
* исследованы продажи по типам мероприятий;
* рассчитаны среднее количество билетов в заказе и средняя выручка на билет;
* построена недельная динамика выручки, заказов, пользователей и средней стоимости заказа;
* определены топ-7 регионов по выручке;
* создан интерактивный дашборд в Yandex DataLens;
* реализованы фильтры по валюте, периоду, типу мероприятия и региону.

## Дашборд

Дашборд включает:

- общую выручку;
- количество заказов;
- среднюю выручку на заказ;
- количество уникальных пользователей;
- недельную динамику выручки, заказов и средней выручки на заказ;
- структуру выручки по типам устройств;
- структуру выручки по типам мероприятий;
- топ-7 регионов по выручке;
- топ-7 событий и площадок по выручке;
- интерактивные фильтры по валюте, периоду, типу мероприятия и региону;
- аналитическую запиской с ключевыми выводами и рекомендациями по результатам анализа.
