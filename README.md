# Data Analytics Projects

Портфолио проектов по анализу данных: исследовательский анализ, A/B-тестирование, SQL, продуктовые метрики и BI-дашборды.

В проектах работаю с данными от первичной проверки и подготовки до расчёта метрик, статистической проверки гипотез, визуализации и формирования аналитических выводов.

## Проекты

| Проект                                                                   | Описание                                                                                                                             | Стек                                                |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------- |
| [Анализ пользовательского спроса Яндекс Афиши](./yandex-afisha-analysis) | Исследовательский анализ пользовательского спроса, динамики заказов, мероприятий и поведения пользователей.                          | Python, Pandas, NumPy, Matplotlib, SciPy            |
| [A/B-тест рекомендательного алгоритма](./ab-test-analysis)               | Планирование и анализ A/B-теста: расчёт выборки, проверка сплита, анализ групп и статистическая проверка изменения ключевой метрики. | Python, Pandas, Matplotlib, SciPy, statsmodels      |
| [Анализ продаж билетов и BI-дашборд](./event-sales-bi-analysis)          | Анализ выручки, заказов, устройств, мероприятий и регионов с помощью SQL и создание интерактивного дашборда.                         | SQL, PostgreSQL, Yandex DataLens                    |
| [Анализ ключевых бизнес-метрик](./product-metrics-analysis)              | Расчёт DAU, Conversion Rate, среднего чека, LTV и Retention Rate, когортный анализ и визуализация результатов в DataLens.            | SQL, PostgreSQL, Yandex DataLens, Product Analytics |

## Навыки и инструменты

**SQL**

* JOIN и CTE
* агрегатные функции
* оконные функции
* DATE_TRUNC
* расчёт долей и бизнес-метрик
* когортный анализ

**Python**

* Pandas
* NumPy
* Matplotlib
* SciPy
* statsmodels
* исследовательский анализ данных
* статистическая проверка гипотез
* A/B-тестирование

**BI**

* Yandex DataLens
* интерактивные дашборды
* KPI и бизнес-метрики
* фильтрация и сегментация данных
* подготовка аналитических выводов

## Структура репозитория

Каждый проект находится в отдельной папке и содержит собственный `README.md` с описанием задачи, этапов анализа и результатов.

Исходные учебные датасеты в репозитории не публикуются.
